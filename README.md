# Практическое задание 3: Intents

## Цель задания
Научиться работать с явными, неявными и системными интентами.

## Что реализовано
1. **Явный Intent** — передача текста из MainActivity в SecondActivity
2. **Неявный Intent** — звонок по номеру телефона (ACTION_DIAL)
3. **Системный Intent** — шаринг текста через ACTION_SEND

## Валидация
Все поля проверяются на пустоту перед выполнением действия.
